Honest scope

This is a pipeline probe, not the shipped game: it implements the full host ABI and renders a procedural dune/rider scene in Rust. The Zig game is 806 KB; this probe is a couple of KB. A complete Rust port would land in the same order of magnitude as the Zig build — same kind of code, no free lunch either way. The point proven here is that the swap is drop-in at the wasm boundary.
